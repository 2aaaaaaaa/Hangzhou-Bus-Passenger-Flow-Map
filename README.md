# 杭州公交客流潮位图

《大数据可视化》课程设计，使用 Three.js 和 Apache ECharts 展示杭州公交站点客流。项目把 2026 年 8 月 14 日至 9 月 28 日的 46 天历史记录放进同一张可交互的城市地图，方便按日期、时段、行政区和站点查看客流分布。

## 本地运行

下载并解压完整项目，双击 `index.html`，建议使用 Chrome 或 Edge。项目是静态网页，依赖和演示数据都随目录提供，无需安装 npm 包或配置 API Key。

也可以在 Windows 双击 `启动.cmd`，或在项目根目录运行 `python -m http.server 8080`，再打开 [http://localhost:8080/](http://localhost:8080/)。访问 [离线模式](http://localhost:8080/?offline) 可跳过在线地图瓦片，使用内置矢量路网。

## 可以怎样看

- **查看客流变化**：切换日期，拖动时间轴或播放。客流柱的高度和颜色随当前时刻更新，也可以切换到全局热力图或 2D 俯视。
- **由图表定位地图**：打开「分析」，比较各区四时段堆叠横条图和占比环形图。点击行政区，地图高亮该区并移动镜头。点击趋势图可换日，点击站点排名可定位站点。
- **查看站点和线路**：搜索站名或点击地图中的标记，查看站点的小时记录。地图提供 32 个核心枢纽和 10 条代表线路的浏览入口。
- **比较广告候选点**：通过气泡图比较 12 个预设路口的周边站点客流和线路指标，点击气泡查看对应路口。

## 数据来源与口径

客流数据包标注的来源是浙江省数据开放平台、杭州市城投集团。公交线路、站点坐标和行政区边界等地理数据随项目保存。更多字段口径见网页右上角「数据说明」。

- 全市合计与全市逐时图使用当日全量记录。分区图、站点排名和地图客流柱基于固定的 1,800 个站点样本，各日覆盖率会变化。
- 缺失小时留空。平滑模式只在相邻有记录的小时之间插值，节假日和雨天模式使用假设系数，页面会标识这些展示值。
- 广告候选点按约 500 米直线半径聚合站点记录。OTS 是结合邻域客流与线路数计算的相对比较分数。地图中的车辆为线路动画，建筑含示意体块。
